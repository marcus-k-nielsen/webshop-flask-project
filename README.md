# WebShop Flask Project

A small web shop application built with **Python, Flask and Object-Oriented Programming (OOP)**.

The project was developed as a school project to practice building a web application with Flask and working with a database-backed webshop.

## Overview

The application provides the basic structure of an online webshop and was built to explore how a Flask application can be structured using classes and templates.

The main focus of the project was:

* Building a web application with Flask
* Using Object-Oriented Programming
* Working with a database
* Creating reusable Python classes
* Connecting backend logic with HTML templates
* Structuring a small web application

## Technologies

* **Python**
* **Flask**
* **HTML / Jinja2**
* **CSS**
* **Database**
* **Object-Oriented Programming**

### Main components

**`app.py`**
The main Flask application responsible for starting the web server and handling the application logic.

**`classes/`**
Contains the Python classes used by the application. This is where the OOP part of the project is primarily implemented.

**`templates/`**
Contains the HTML/Jinja2 templates used to generate the web pages.

**`static/`**
Contains static resources such as CSS and other frontend assets.

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/marcus-k-nielsen/webshop-flask-project.git
cd webshop-flask-project
```

### 2. Install the required packages

Make sure Python is installed, then install Flask:

```bash
pip install flask
```

If the project uses additional packages, install those as required.

### 3. Start the application

```bash
python app.py
```

The Flask development server should then be available locally.
